IntroDB

Not needed to skip: IntroDB timings are read without a key, sending only the show's IMDb id and season/episode. A free key from introdb.app is only for submitting timings, which is not built yet.

Supabase

Optional cloud sync - your own private project

Supabase dashboard → Project Settings → API → Project URL.

Project Settings → API Keys. Use the publishable key (it starts with sb_publishable_). The legacy anon key (it starts with eyJ) also works. Never use a secret key. SkipStream does not run SQL in your project. You run the setup script one time (this page shows how).

One more step, one time only. SkipStream cannot create tables in your project. Your anon key does not allow that, and that keeps your project safe. Run the setup script yourself:

  1. Press Open the SQL editor. Supabase opens with the script filled in. Log in if Supabase asks.
  2. In Supabase, press Run.
  3. Come back here and press Check again.
Open the SQL editor

The script adds two tables (playback_states and user_settings) and the functions SkipStream calls. It changes nothing else, and you can run it again safely. If your project already has tables with these names for something else, use a new project.

OpenSubtitles

Auto-subtitle fetch - optional, increases quota

Without an account: 5 downloads a day. With a free account: 20 a day. VIP accounts get more. After you log in, this page shows the number from OpenSubtitles. Set the subtitle language in the popup. Backup & Restore

One file restores everything on another browser or after a reinstall.
  1. Save: pick what to include, type a passphrase if keys are on, press Export All.
  2. Restore: on the other browser, type the same passphrase, press Import Backup, pick the file.
  3. The page reloads with everything back. Nothing is deleted on either browser.
