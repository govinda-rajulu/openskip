# DOCS-DRIFT
Load when: weekly rotation, or after a release.
Files: README.md, PRIVACY.md, AGENTS.md, HOW_TO_RELEASE.md, TESTING.md

Find a sentence that promises something the code does not do, or names a file, setting,
workflow, version or number that is gone or wrong. You see only the document, so the claim
must name the code it contradicts (file and function or setting) so the owner can check it.
LESSONS 3 Oct: "Read the promise, then the code": README said "resume on any device" while
every install had its own id. Severity: high when PRIVACY.md is wrong, medium for user docs,
low for developer docs.
