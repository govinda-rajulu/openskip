# FEATURE-SPEC
Load when: turning an `agent-task` feature issue into a spec before any code.
Files: (none: workers read the files the spec names)

A spec is done when someone who has not seen the chat can build it. It has:
1. The user's words and the problem in one paragraph.
2. What changes for the user, step by step, including every message text.
3. Data: new storage keys, what leaves the browser and to which host. PRIVACY.md changes.
4. Acceptance checks: each one becomes a test that fails on the current code.
5. A device-test list (laptop Firefox, phone Firefox, Chrome or Edge), with the version badge
   check first (LESSONS 3 Oct).
6. What is out of scope.
Never fill in an owner decision (accounts, data, publishing, deletion). List it as a question.
