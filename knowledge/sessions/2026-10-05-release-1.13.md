## Decisions

- Skip sources: kinds combine across sources; inside one kind one source gives all its parts
  (IntroDB > TheIntroDB > SkipDB > AniSkip > Anime Skip). Never mix two sources in one kind:
  times can come from different releases.
- Find page parts by what they do (role, size, place, value), never by one player's class
  names; never insert into another app's DOM. Known names only add points.
- A site is its name without the ending (`_siteFamily`): rules, History and resume survive a
  move to a new domain. Cost: example.com and example.net count as one site.
- Logos: the service's own site icon, DuckDuckGo icons as fallback, loaded only when Settings
  > Accounts or Sources & help opens (PRIVACY.md). README uses the same icons.
- Settings in 5S order: Features, Customise, Accounts, History, Stats, Data, Sources & help.
- Outros ask first by default (credit scenes); "Intros + recaps" is the default mode.
- Sending your own skip times: later, after the 1.14 login (ROADMAP).
